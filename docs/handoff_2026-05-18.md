## 2) 다음 담당자 재개용 스크립트 (다음 채팅에 그대로 붙여넣기)
```text
작업 재개 요청.

[환경]
- Windows repo root: D:/01. PROJECTS/master/UE/AERION/Aerion-Airsim
- WSL distro: Ubuntu-22.04
- branch: branc/airsim-ros2-bridge

[우선 확인]
1) git status --short
2) git pull --ff-only origin branc/airsim-ros2-bridge

[실행 순서]
1) (Windows) WSL로 코드 복사
   powershell -ExecutionPolicy Bypass -File scripts/copy_bridge_to_wsl.ps1
2) (Windows) WSL 빌드
   powershell -ExecutionPolicy Bypass -File scripts/build_bridge_in_wsl.ps1
3) (WSL) PX4 다중 인스턴스 실행
   ./scripts/launch_px4_instances.sh
4) (WSL) MAVROS 다중 인스턴스 실행
   ./scripts/launch_mavros_px4_instances.sh
5) (WSL) ROS2 bridge 실행
   ./scripts/run_airsim_ros2_bridge_instances.sh
6) (WSL) 스모크 테스트
   ./scripts/smoke_airsim_ros2_bridge.sh

[검증 포인트]
- /drone1, /drone2, /drone3 제어/상태 토픽 publish/subscribe 정상
- takeoff -> 전진 probe -> land 시퀀스 정상 수행
- 필요 시 카메라 토픽은 마지막에 확인

[문서]
- docs/mavros_topic_mapping.md
```
